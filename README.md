# my-code-lab

A personal full-stack learning repository focused on backend, frontend, and DSA practice.

## Repository Structure

Main content lives in:

- `full-stack-ai/backend` – Node.js, Express, MongoDB/Mongoose practice (day-wise progression)
- `full-stack-ai/frontend` – HTML, CSS, JavaScript, React, and GSAP learning/projects
- `full-stack-ai/dsa` – JavaScript-based DSA/problem-solving exercises

## Key Technologies

- JavaScript (core)
- Node.js
- Express.js
- MongoDB + Mongoose
- React
- Vite
- Tailwind CSS
- GSAP

## How the Code Is Organized

- Most folders are split by **day** or **topic**.
- Backend folders evolve from fundamentals (`http`, basic Express) to structured API projects (routes/controllers/models).
- Frontend folders include both concept practice and mini-projects.
- DSA folders contain focused coding exercises.

## Getting Started

This repository contains multiple independent practice projects.

1. Go to the project folder you want to run.
2. Install dependencies (if `package.json` exists):
   ```bash
   npm install
   ```
3. Start the project using its scripts, for example:
   ```bash
   npm run dev
   ```
   or
   ```bash
   npm start
   ```

## Notes

- Not all folders are runnable apps; some are learning notes or single-file exercises.
- Environment variables are used in some backend projects (for example, MongoDB connection setups).
